# Voice references

`patch.wav`, `boo.wav` and `nibbles.wav` are original voices designed with Breeze TTS
(prompts and seeds in `voices.json`).

The fan-character references (Trogdor/Strong Bad, Sorting Hat, Dobby, Voldemort) are short
clips from copyrighted recordings. They are not published here; `voices.json` records each
clip's source and cut so a local copy can be recreated. Place them in this directory with the
file names `voices.json` expects.
